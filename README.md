# Fondos Inmobiliarios SITU · panel

Pantalla de acceso del panel: https://situinmobiliaria.github.io/fondosinmobiliarios-panel/

Este repositorio es público y **no contiene datos**: solo la página de login. Al iniciar sesión con Google (solo cuentas @situ.cl, cliente OAuth interno), la página pide el panel y los PDFs a una web app de Google Apps Script que verifica el token (dominio situ.cl) y los lee del repositorio privado `situinmobiliaria/fondosinmobiliarios`.
